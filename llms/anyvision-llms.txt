# AnyVision (Oosto)

> AnyVision Interactive Technologies is an Israeli computer-vision company that rebranded as Oosto in
> October 2021 and was acquired by Metropolis Technologies in January 2025. It builds real-time facial
> recognition and video analytics ("Vision AI") for physical security: Oosto OnWatch (watchlist
> alerting and person-of-interest monitoring), Oosto OnAccess (touchless facial access control), and
> Oosto Protect (cloud alerting). Deployment is on-premise, at the edge on a Vision AI Appliance, on
> smart cameras via embedded SDKs, or in the cloud.

This file was GENERATED by API Evangelist from public sources on 2026-08-06. The provider does not
publish an llms.txt (https://oosto.com/llms.txt returns 404).

## What an agent needs to know first

- **There is no public API.** Both product APIs ship with the customer's own installation. There is no
  vendor-hosted base URL, no self-serve signup, and no API key you can obtain online.
- **The reference documentation is gated.** https://knowledge.oosto.com/docs 302s to an email
  one-time-password login. Nothing machine-readable is served to an anonymous client.
- **No OpenAPI, no AsyncAPI, no GraphQL SDL, no MCP server, no A2A agent card** is published on any
  Oosto host. All /.well-known/ paths on oosto.com return 404; every path on knowledge.oosto.com
  returns a 200 HTML soft-404 and should be ignored.
- The only public evidence of the API surface is the vendor's sample-code repository on GitHub.

## APIs

- [Oosto OnWatch API](https://github.com/AnyVisionltd/oosto-api-sample-code/tree/master/OnWatch):
  REST + Socket.IO under the `/bt/api` base path on the customer's OnWatch server. Bearer JWT from
  `POST /bt/api/login`, EULA acknowledgement at `POST /bt/api/eula`, paged reads such as
  `GET /bt/api/roles?offset=&limit=&sortOrder=`, and a Socket.IO stream at `/bt/api/socket.io`
  emitting `track:created` detection events.
- [Oosto OnAccess API](https://github.com/AnyVisionltd/oosto-api-sample-code/tree/master/OnAccess):
  REST under the `/abx/api` base path. Bearer JWT from `POST /abx/api/login`, face-feature extraction
  at `POST /abx/api/external-functions/extract-faces-from-image` (multipart), member enrolment at
  `POST /abx/api/members`.
